# POKOPIE

Game Boy Color multi-game ROM (EPITECH 2026 project): a title screen, a walkable menu, and three
games (Wolf3D, Tyrunt, Snake) with high scores saved in battery-backed cartridge RAM. Written in C
with GBDK-2020; the ROM is 256 KB (16 banks) on an MBC5 + RAM + battery cartridge. How the modules
fit together is in [docs/architecture.md](docs/architecture.md).

## Install

1. Download GBDK-2020 4.5.0 and extract it to `~/.local/opt/gbdk-4.5.0`, or set `GBDKDIR` to its
   location (see [Configuration](#configuration)).
2. Optional, to run the ROM: RetroArch with the gambatte libretro core (for `make play`), or
   Emulicious and Java (for `make emulicious`).

## Run

```sh
make              # build pokopie.gb (same as make all)
make play         # build, then launch in RetroArch (gambatte core)
make emulicious   # build, then launch in Emulicious
make rom-usage    # print ROM space usage
make clean        # remove .o, .lst, .asm, .sym files, pokopie.gb and *.map, *.ihx, *.noi
make fclean       # same as clean
make re           # clean, then build
```

## Test

There are no automated tests. Test manually with `make emulicious` (debugger, SRAM viewer to check
that high scores persist) or `make play`.

## Configuration

| name | default | effect |
|---|---|---|
| `GBDKDIR` | `$(HOME)/.local/opt/gbdk-4.5.0` | GBDK install whose `bin/lcc` builds the ROM; override with `make GBDKDIR=...` |
| `ROM_BANKS` | `16` | ROM size in 16 KB banks |

The emulator paths are hardcoded in the Makefile and must be edited per machine:
`/usr/lib/x86_64-linux-gnu/libretro/gambatte_libretro.so` in `play` and
`/home/thomas/Emulicious/Emulicious.jar` in `emulicious`.

## Layout

| module | path | one line |
|---|---|---|
| headers | `include/` | Shared types (`game_t`, entities, map, window), per-game `init_X`/`update_X` declarations, asset declarations |
| core | `src/cartridge.c`, `src/entities/`, `src/save/` | `main` loop, entity sprite drawing, `high_scores` in save RAM |
| game-utils | `src/games/utils/` | Game switching (`init_game`), palette fades, text printing, high-score saving |
| game-starting-screen | `src/games/starting_screen/` | Title screen: logo scrolls up, credits scroll in, START opens the menu |
| game-menu | `src/games/menu/` | Overworld map; walk onto a door to start a game, popup shows its high score |
| game-wolf3d | `src/games/wolf3d/` | First-person maze (raycaster); reach the exit before the score runs out |
| game-tyrunt | `src/games/tyrunt/` | Endless runner: jump over trees and Tylton, pick up bonuses |
| game-snake | `src/games/Snake/` | Snake on a grid; speed rises with the score |
| assets-menu | `src/assets/menu/`, `src/assets/font.c`, `src/assets/sounds.c` | Generated graphics for the menu and the font |
| assets-start-tyrunt | `src/assets/starting_screen/`, `src/assets/tyrunt/` | Generated graphics for the title screen and Tyrunt |
| assets-wolf3d | `src/assets/wolf3d/` | Wolf3D level map and gun/Machop tiles |

Source images for the assets are in `rawAssets/`. Tile and sprite `.c`/`.h` files are generated by
png2asset (its arguments are in each file's first lines): edit the image and regenerate rather than
editing them by hand. `sounds.c`, `menu/menu_tilemap.c`, `starting_screen/pokopie_tilemap.c` and
`wolf3d/map.c` have no png2asset header. `.asm`, `.lst`, `.o` and `.sym` files next to the sources are build outputs.
